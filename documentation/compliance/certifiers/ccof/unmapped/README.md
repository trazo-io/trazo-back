One file per Trazo OSP module, named `<module_key>.yaml`, listing questions in that module which
no CCOF **grower** form asks. Per-module files rather than one shared file so that work on
different forms never collides.

```yaml
questions:
  g2_0_fraud_prevention.fraud_risk_areas: "Common OSP § 2. CCOF folds fraud prevention into G8.0 D
    as three questions and does not ask for a risk-area inventory."
```

Every entry needs a reason. Most exist because the federal Common OSP or the regulation asks for
something CCOF's grower overlay leaves implicit — that is the superset story, not an excuse.
